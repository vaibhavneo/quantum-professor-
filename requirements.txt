# mathlab.py — sympy does the algebra, numpy does the eigensolve. These were
# missing, so /api/math, /api/ode and /api/schrodinger would have raised
# ImportError on any host that installs only what is listed here. The Math Lab
# worked locally purely because both happened to be on the machine already.
sympy>=1.12
numpy>=1.24

# scipy is here for exactly one call: eigh_tridiagonal. The Hamiltonian is
# tridiagonal and only the lowest few states are wanted, so the dense
# numpy.linalg.eigh it replaces was doing O(N^3) work to discard almost all of
# it. Unnoticeable locally; on the deployed container a 400-point solve took
# 19 s and 1200 points never finished. mathlab falls back to the dense solve
# if this import fails, so the app still answers without it — just slowly.
scipy>=1.10
